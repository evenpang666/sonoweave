# 2026-10-22 后台真实声音测试

使用用户正在播放的英语视频，经默认输出设备的 WASAPI 回环进入真实识别、翻译、缓存和字幕窗口。测试阻断 Python socket 连接，未保存录音。实际文本及截图仅存于忽略的 `.cache`，不随程序发布。测试时间按模型就绪后的观察时长计算，加载阶段另外约 10 秒。

## 发现的问题及处理

1. 初始连续 180 秒观察中，采集与字幕更新没有持续积压，但人工核对缓存发现，部分完整英文段落被译成“但 I”等无关短语，并覆盖此前较完整译文。原有固定短句示例可能被小模型模仿。删除该示例，明确完整翻译，并加入长英文原文对应中文译文异常短时的重试检查。复用与语义校准均不能仅靠更新次数判定正确。
2. 中间版本的 120 秒复测检测到一次约 12 秒停滞，测试失败：原文继续增长，但模型反复回显英文，输出校验拒绝发布，因此保留上一条字幕。进一步调整备用提示词，将原文作为引号包围的独立内容。对同一问题段落回放，较长版本可以恢复翻译，但部分较短版本仍回显；这是尚未完全解决的小模型可靠性问题。
3. 人名与口语仍有误识别、直译和局部漏译。没有参考转录或专业人工逐句标注，不能给出准确率。Whisper base 与 Qwen3-1.7B 的模型规模均未更换。
4. 一轮 90 秒复测记录到一次 SoundCard `data discontinuity in recording` 告警，之后仍有字幕更新。它提示音频缓冲出现不连续，可能有短暂丢样；没有证据确认具体遗漏了哪些词。该轮同时运行打包及独立模型回放，不能据此断言原因。

## 复测

去除固定示例、补充校验及调整备用指令后的 90 秒实声观察：144 次字幕更新，9 段原文/译文缓存；处理耗时中位数 0.203 秒，P95 为 0.469 秒，最长 1.219 秒；未检测到原文增长而字幕持续停滞，未收到最终失败的翻译错误事件。该轮发生过上述音频缓冲告警。

最终发布代码另做 60 秒实声确认：72 次字幕更新，5 段原文/译文缓存；成功输出的处理耗时中位数 0.203 秒，P95 为 1.172 秒，最长 2.782 秒。未收到最终失败的翻译错误事件，未记录音频缓冲告警。计数型停滞检测为 0，但相邻字幕更新最长间隔为 **6.594 秒**；该指标不区分音频静音、识别文本未变及模型输出被拒绝，因此不能将前者解读为从不等待。结果列于同目录 `runtime-test-20261022.json`，其中仅保留计数、耗时和告警，不含视频内容。

处理耗时从音频窗口就绪算到字幕输出，不包含约 0.9 秒首次分窗、后续约 0.55 秒更新节奏、播放器自身缓冲及初次模型加载。P95 仅统计成功输出的字幕，不能反映未成功翻译的内容。

48 项自动化回归测试通过。`tools/verify_bundle.py --require-captions` 验证发布程序的界面、附带模型、实际系统音频及译文缓存输出，三项均通过。发布文件为 `dist/SonoWeave/SonoWeave.exe`，版本 0.3.1。四轮实声观察合计 450 秒（7.5 分钟），其中包含用于暴露问题的初始及中间版本，不能全算作最终版本的稳定运行时长。

## 结论

当前系统可以持续采集、积累原文与译文并更新字幕，已修复固定示例污染及严重缩水输出直接覆盖缓存的问题。但小模型仍可能错译、漏译或回显；遇到校验不通过时，字幕可能等待后续语音。不能将本轮短时复测理解为翻译可靠性或长期无丢音保证。
